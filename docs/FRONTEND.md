# 前端与体验

VerdictPilot 的前端直接由 FastAPI 在 `/` 与 `/assets` 提供，不需要 Node 构建、远程字体或外部前端 CDN。`web/index.html` 定义导航、工作区和搜索对话框；`web/app.js` 实现 hash 路由与操作流程；`web/styles.css` 定义组件与响应式布局。

## 快速体验

```bash
uv sync --frozen --extra dev
uv run --frozen verdictpilot serve --port 8000
```

打开 `http://127.0.0.1:8000`。默认无需模型 Key，代码执行关闭；可以阅读课程、交测验、写笔记、检索知识、运行不含代码的离线诊断。首页数据来自 API，没有预置完成数或示例个人成绩。

推荐从三个操作开始：

1. 在「学习路线」打开复杂度课程，完成测验并在旁边写一条笔记。刷新后核对最佳成绩和笔记。
2. 在「题目训练」使用关键词、标签、难度、完成状态筛选；清除筛选可以回到全部 12 道题。
3. 在「诊断工作台」保留默认题面直接提交，打开来源资料和调用轨迹。离线规则提供可检查的检索与流程结果，不模拟模型推理质量。

需要运行自己的可信代码时，检查源代码后用 `serve --trusted-local` 显式开启本机执行。限制和 Docker 后端说明见 [THREAT_MODEL.md](THREAT_MODEL.md)。

## 页面与学习流程

| 页面 | 作用 | 状态来自哪里 |
| --- | --- | --- |
| 学习概览 | 推荐下一课、查看通过数、复习数与活动 | `GET /v1/dashboard` 的实际记录 |
| 学习路线与课程 | 查看前置要求、课程、练习、测验与解析 | 版本化课程和服务端评分；练习勾选是自查 |
| 题目训练 | 搜索题目、组合筛选并排序 | 固定题库与当前学习标识的提交状态 |
| 训练工作台 | 题面、样例、分层提示、题解、编辑器与测试结果 | 公开题目数据、草稿、后台运行结果 |
| 诊断工作台 | 带题面和代码分析，查来源与事件 | 离线规则或可选模型工具调用 |
| 项目工坊 | 阅读实施计划并记录实测里程碑 | 使用者填写的命令、产物与指标，未自动独立核验 |
| 知识资料库 | 搜索片段，打开完整来源 | 本地 Markdown 文档的 BM25 排名 |
| 错题与复习 | 从错误运行记录教训并提交复习反馈 | 有执行证据的错误与简单间隔规则 |
| 运行记录与统计 | 查看历史、代码、结果、事件及趋势 | SQLite 运行、测验与复习记录 |
| 空间设置 | 保存学习档案、查看环境、导出记录 | 浏览器学习标识对应的服务器数据 |

## 编辑器

代码编辑器是带行号的原生 textarea，不依赖大型编辑器包。支持以下操作：

| 操作 | 行为 |
| --- | --- |
| Tab | 单光标插入 4 个空格；选中多行时按行缩进 |
| Shift Tab | 去除选中行首最多 4 个空格或 1 个 Tab |
| Ctrl / Cmd S | 保存当前代码到浏览器和服务端 |
| Ctrl / Cmd Enter | 提交题库测试；执行关闭时明确显示对应结果 |
| Esc | 离开代码编辑区，将焦点移到保存按钮；后续 Tab 可正常遍历界面 |
| 复制 | 复制当前代码，使用浏览器 Clipboard API；需安全上下文，localhost 可用 |
| 下载 | 导出当前编辑内容为 `{题目ID}-solution.cpp` |
| 恢复模板 | 保存当前内容到临时撤销槽，并替换为该题起始代码 |
| 撤销恢复 | 找回最近一次恢复模板前的代码；离开页面后临时撤销槽清空 |

底部显示光标行列与字符数。草稿输入后立即保存在 localStorage，停止输入 700 ms 后保存服务端。相同题目的保存请求串行执行，防止旧请求慢于新请求时覆盖服务器的新版本；成功状态只标记与当前草稿一致的响应。网络保存失败会显示浏览器已有副本。

返回同一浏览器会话的题目页面，会恢复最近一次任务 ID 并读取结果；任务尚未完成时继续轮询。轮询随路由变化停止，任务仍保存在服务端的运行记录中。不会因打开页面而重新运行代码。

## 笔记与数据恢复

课程笔记在输入时保存浏览器副本，随后写入 SQLite；刷新时比较更新时间并优先恢复较新的浏览器副本。服务暂时不可用时不会直接丢掉已输入笔记。自动保存队列按课程隔离，输入新的笔记不会让旧响应误报当前内容已经保存。

首次访问生成的学习标识保存在当前浏览器，浏览器副本和会话任务也按这个标识隔离。清理站点数据会失去浏览器里的标识和副本。需要迁移或备份时，在「空间设置」导出学习证据；目前没有前端导入功能。本地学习标识不是鉴权令牌，当前界面面向本机单人训练。

## 反馈、键盘与窄屏

- 顶部显示代码执行或离线学习的就绪状态；请求失败有可读错误和重试入口。
- 空列表解释接下来可以做什么；题库空结果提供清除筛选，结果数量随筛选更新。
- 诊断、代码提交和保存均有加载或保存状态；复习反馈提交期间禁用该组按钮，避免重复点击。
- Ctrl / Cmd K 打开课程与题目搜索；Esc 关闭对话框；标准 Tab 可定位按钮与链接。
- 主导航用 `aria-current` 标识当前页，筛选标签使用 `aria-pressed`，移动菜单维护 `aria-expanded`。
- 960 px 以下将长工作区切成单列；650 px 以下导航从菜单打开。训练页在手机上将代码、题目和测试结果分为三个区域，可直接切换；提交测试后自动打开结果。代码自身可以横向滚动，以保持缩进。
- 题库采用可扫读的题目行，关键词、标签、难度、完成状态和排序写入地址栏的 hash 查询参数；刷新或分享当前地址可以恢复筛选。
- 题目资料与手机训练区域的切换按钮支持方向键、Home 和 End，使用 `aria-pressed` 提示当前区域。跳到主内容链接、搜索对话框名称、笔记标签、实时保存反馈均有明确的辅助技术语义。
- 测试用例 JSON 无法解析时，在输入框下显示如何修正，并将焦点移到该字段；弹窗内容滚动不会连带滚动页面，减少动态效果设置会关闭加载动画与过渡。
- 代码与笔记自动保存浏览器副本；档案、诊断和项目表单存在未提交修改时，离开页面会提示，避免误导航丢失输入。提交失败保留提醒，成功后解除。
- `prefers-reduced-motion` 开启时关闭旋转和过渡动画。

```bash
uv sync --frozen --extra dev --extra browser
uv run --frozen --extra dev --extra browser python tools/smoke_browser.py --channel chrome
```

默认使用已安装 Chrome。需要 Playwright 自带 Chromium 时，先执行 `uv run --extra browser playwright install chromium`，再传 `--channel chromium`。

## 设计与维护

品牌标识由 V 形验证笔画与运行状态点组成，素材见 `web/logo.svg` 与 `docs/assets/`。主题颜色定义在 CSS 根变量中：主要操作用深青色，编辑器和导航用偏青深蓝，内容区使用白色与冷灰；暖橙只用于待复习和提醒。中文课程正文为 16 px，控件以 14 px 为主，次级信息为 12 px；代码区使用本地 Cascadia Code / Consolas。所有素材由本地文件提供；服务显式注册标准 SVG MIME 类型，避免 Windows 注册表将其识别为 `image/svg` 而导致破图。

内部页面按任务组织：概览优先展示下一课入口和真实进度；题库是行式清单；课程是长文阅读与笔记边栏；训练工作台保留题面和代码的双栏，结果逐条列出失败输出；诊断按问题输入和证据阅读分区；错题显示原始运行入口和复习动作。页面标题直接标明所在工具，布局不依赖营销标语或装饰插画。

动态题面、笔记、代码、错误和诊断 Markdown 先转义再插入界面，Markdown 只支持小范围语法，不允许原始 HTML。路由异步加载和来源搜索在响应后核对路由序号，避免离开页面后的旧结果写入新页面。

当前未实现语法高亮、语言服务器、代码补全、主题切换、后端取消任务或多端草稿冲突合并。需要扩展编辑能力时，应先保留现有快捷键、保存与执行状态测试，再评估引入编辑器依赖的体积和维护成本。

2026-10-14 Chrome 完整流程验收通过，整体答案错误与修复后通过分别核对；题库 URL 刷新恢复、非法 JSON 行内错误及输入恢复、手机三种区域切换也通过。训练页在 320、390、768、1024 px 下无整页横向溢出，未出现 JavaScript 错误。记录见 [browser-workbench.json](browser-workbench.json)。
