# 竞赛代码诊断：CE、RE、WA 与 TLE

先按可观测现象分类，再缩小范围。CE 读取编译器首个关键错误；RE 检查越界、空容器、除零、递归深度；WA 构造最小反例；TLE 对照数据规模重新计算复杂度。

诊断顺序：

1. 固定输入并确保问题可以重复出现。
2. 从最小失败样例开始，打印状态不变量而不是大量中间变量。
3. 对拍时准备可信的暴力实现和随机数据生成器，保存第一个反例。
4. 修复后运行原失败样例、边界样例和回归样例。
5. 记录“症状、根因、修复、不变量”，避免只收藏最终代码。

常见 WA 来源是边界、整数溢出、排序稳定性、重复元素、答案初始化和读题中的“至少/至多/恰好”。
